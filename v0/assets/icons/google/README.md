# Google Material Symbols

Ícones locais usados apenas para orientar o menu mobile:

- `home`;
- `route`;
- `compare_arrows`;
- `verified`.

Origem: [Google Material Design Icons](https://github.com/google/material-design-icons), variante `materialsymbolsrounded`, 24 px. Os arquivos foram renomeados e receberam a cor local `#dbe4ff`; os vetores não foram redesenhados.
