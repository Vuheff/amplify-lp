# Pesquisa da v0

Esta pasta separa **evidência**, **decisão** e **material candidato**.

## Estudos consolidados

- [`LANDING-WEBINAR.md`](LANDING-WEBINAR.md) — arquitetura de informação e sequência comercial.
- [`BEHAVIORAL-DESIGN.md`](BEHAVIORAL-DESIGN.md) — princípios psicológicos, uso ético e limites.
- [`DESIGN-PSYCHOLOGY.md`](DESIGN-PSYCHOLOGY.md) — percepção, atenção, memória e decisão traduzidas em critérios de design.
- [`BRAND-DESIGN-SYSTEM.md`](BRAND-DESIGN-SYSTEM.md) — missão, voz, tokens candidatos, grid, componentes e acessibilidade.
- [`STACK-MODULES.md`](STACK-MODULES.md) — framework, bibliotecas, critérios de adoção e módulos de estudo.
- [`REFERENCE-MAP.md`](REFERENCE-MAP.md) — fontes primárias/oficiais e uso autorizado de cada uma.
- [`VISUAL-REFERENCES.md`](VISUAL-REFERENCES.md) — leitura crítica das referências Amplify Marcas e Dixie.

## Materiais

- `inputs/landing-direction-source.txt` — briefing original fornecido pelo usuário, preservado sem edição.
- `assets-candidates/` — logo, pessoas, marcas, provas e fotos brutas ainda não aprovados para produção.
- `references/visual/` — referências visuais externas preservadas para análise, nunca para cópia automática.

Um arquivo estar nesta pasta não autoriza seu uso público. Claims, marcas, imagens e números só migram para produção quando tiverem fonte, permissão, responsável e data de revisão.
